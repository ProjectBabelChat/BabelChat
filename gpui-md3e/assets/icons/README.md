# Icons

A subset of [Material Symbols](https://github.com/google/material-design-icons)
(Rounded, 24px, weight 400), © Google, licensed under the Apache License 2.0.

Each icon is stored as `<name>.svg` (outlined) and `<name>-fill.svg` (filled).
Run `../../scripts/fetch_icons.sh` after editing the list in that script;
`build.rs` turns every file here into a variant of the `Icon` enum.
